# 📱 NahomiCalc - Calculadora Científica Avanzada

![Versión](https://img.shields.io/badge/versión-1.0-blue)
![Licencia](https://img.shields.io/badge/licencia-MIT-green)

Calculadora científica completa con visualizador de gráficos en tiempo real, tabla de valores con derivadas e integrales, y sistema de historial persistente.

## ✨ Características

- 🔢 **Operaciones básicas y científicas** (seno, coseno, logaritmos, factorial, potencia)
- 📊 **Visualizador de gráficos interactivo** (zoom, autoescala, export PNG)
- 📈 **Tabla de valores** con derivada numérica, segunda derivada e integral aproximada
- 💾 **Historial persistente** (import/export JSON, 50 últimas operaciones)
- 🔄 **Conversión de bases** (binario, hexadecimal, base62)
- 🧮 **Operaciones con matrices** (suma, multiplicación, determinante, transpuesta)
- 🌓 **Modo oscuro/claro** con persistencia
- 📱 **Diseño responsive** y atajos de teclado

## 🚀 Uso rápido

1. Clona el repositorio
2. Abre `index.html` en tu navegador
3. ¡Listo! No necesita instalación ni servidor
